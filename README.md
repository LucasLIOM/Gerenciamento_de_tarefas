# Gerenciamento de Tarefas

Projeto simples desenvolvido com Java, Spring Boot e Maven para gerenciamento de tarefas e usuários.

## 🚀 Tecnologias utilizadas

- Java
- Spring Boot
- Maven
- MySQL
- JPA / Hibernate
